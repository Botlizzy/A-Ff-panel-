# ELIMINATOR SENSI GENERATOR

Static website with:
- Login page that requires access code: `ELIMINATE`
- Device input + “Get sensi” generator
- Copy button
- Blue + Red animated background

## Deploy (Netlify)

1. Drag-and-drop this folder into Netlify, or connect your repo.
2. Build command: **none**
3. Publish directory: **the folder root**

## Deploy (Vercel)

1. Import the project in Vercel.
2. Framework preset: **Other**
3. Build command: **none**
4. Output directory: **.**

## Notes

- The access code is a **client-side lock** (good for basic gating).  
  For real secure login, you need a backend.
